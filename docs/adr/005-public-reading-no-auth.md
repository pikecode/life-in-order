# ADR-005：公开阅读，不设账号

日期：2026-11-10。状态：按用户明确要求实施，替代 ADR-002 的认证与个人计划部分；PostgreSQL 继续保留。

产品只用于浏览阅读，账号增加验证码、邮件、会话、隐私和数据管理负担，当前没有对应用户价值。选择删除认证运行依赖与关联界面，公开提供知识与辅助检索；只隐藏登录菜单的方案仍需维护失效服务，不采用。

旧页面转到知识目录；旧认证、计划和个人导出接口统一 410，不通过去掉归属检查来开放历史数据。新迁移不创建账号表，不删除已有个人数据。备份继续涵盖历史表，清除或迁移历史数据另行明确范围后实施。

保留匿名最小统计、内容与索引数据库；APP_URL 仅用于服务地址与同源校验。不引入其他身份方案、社交登录或匿名个人计划。符合 KISS/YAGNI，停用响应复用以减少遗漏，公开内容与私人历史数据边界明确。
