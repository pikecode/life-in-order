# 当前路线：探索式知识库

更新：2026-11-10。当前主方向为知识查找、探索与阅读，替代早期行动助手优先级。访谈暂缓，工程验收不能替代市场验证。

1. 当前：阅读优先，首页通过主题、章节和真实标题引导兴趣；每组 8 条连续向下阅读、组末翻组与跨章，目录与可撤销筛选作为辅助，搜索折叠；撤下处理台推广，停用旧账号与计划入口，历史数据保留。
2. 后续：依据真实查询检查排序、零结果、手机阅读与返回路径；优先修复实际卡点。
3. 按需：人工整理专题或细分标签，需求明确后再设计收藏与阅读记录；不提前建设模型代理或推荐平台。
4. 上线：仍需部署信息、HTTPS、内容审阅、隐私协议、备份调度；不再部署账号或邮件服务。

以下为历史实施记录，其中行动助手优先级、多场景扩展与处理台推广已被上述方向替代。历史功能和数据不删除。

# 实施阶段规划

更新：2026-11-09。访谈暂缓，当前授权文档完善及开发；不将开发完成当作市场验证。
