# 技术架构：公开阅读产品

更新：2026-11-10。当前账号、认证与计划服务已移除，历史 ADR 与实施记录保留为演进记录。

## 方案与边界

Next.js + TypeScript 单体、PostgreSQL；静态站可减少服务端运维，但当前检索、匿名统计和固定版本内容已在数据库内，沿用现有架构更简单。无注册、邮箱验证码、用户会话、个人计划或公开的历史个人数据接口。

首页引导兴趣，主题和真实标题直接进入连续阅读；每组最多 8 条，按主题内章节顺序读取，组末翻组。搜索折叠为辅助。成本、收益、证据、来源、原文及署名用共享原生 details 按需展开。

## 模块与数据流

浏览器 → 同源页面/接口 → 输入校验、内容/检索/统计服务 → PostgreSQL。固定快照 → 摘要、编号、许可与引用校验 → 事务导入 → 服务端读取。

`content/` 保留完整来源快照与不可覆盖的历史版本；`content-import.ts` 管理导入，`content-db.ts` 管理目录、标题、正文与阅读邻居；`knowledge-search.ts` 管理主题、受控别名与摘要；界面不持有数据库凭据。

## 数据

source_versions：提交、作者、许可、清单；knowledge_entries：正文、成本收益与引用。content_releases/action_tasks 保留历史内容谱系和导入指纹，不再提供行动产品界面。发布事务、锁、摘要和外键防止部分导入及静默覆盖。

usage_events：短期随机会话、事件、知识定位、检索模式/范围与结果数量；不存原始查询、邮箱、账号标识、完整 IP 或 UA。客户端观察正文进入视口，再累计可见聚焦时间，加载八条不算阅读八条。

迁移只创建公共内容与统计结构，不再创建用户、会话或计划表。已存在的历史个人数据不删除、不通过产品访问，备份工具仍覆盖全部表。生产运行角色只需当前内容与统计权限，无需历史个人表权限。

## 阅读与检索

服务端连续阅读保留稳定 URL，数据库参数化查询计算主题内位置及真实邻居，分组最多读取 8 条正文和少量前后标题。缺失内容展示未找到页，数据库异常显示错误，不伪造空数据。普通链接支持刷新与浏览器前后退；未持久化已读或跨设备进度。

关键词参数化 ILIKE、主题/章节白名单、标题优先和分页；可选本机 Ollama 嵌入、pgvector 精确候选及 RRF 融合。索引按来源、模型摘要和文本规则隔离，不可用时回退关键词。没有独立推荐服务或模型自动拆解。

## 完整来源文档

新增 source_documents（提交+路径主键、分类、完整 Markdown、章节导读、主题、SHA-256/Git blob）、document_chunks（原文位置、文本、摘要）与 document_embeddings（分段+模型版本向量）。完整文档与 772 条派生知识并存；原章节和文档可双向链接，知识搜索补充专题结果，历史核实记录独立分类。使用标准 Markdown 渲染，禁用原始 HTML，安全过滤 URL；支持表格和稳定标题锚点。库与阅读均服务端分页/按文档读取，未新增 CMS 或账户。完整性审计重建 Git 目录树，并检查快照→正文→分段→索引的全部对应，见 ADR-006。

## 接口与安全

公开接口仅健康检查和匿名统计。统计 POST 校验 APP_URL/同源 Host、白名单、2KB 上限、真实知识引用、幂等、五分钟去重和每小时软限量；故障不阻断阅读，无公开统计读取接口。

旧 /api/auth/*、/api/plans、/api/plans/:id、/api/account/export 返回统一 410 且 no-store，不读取 Cookie 或个人数据，不发送邮件。旧账号、登录、计划和处理台页面转到知识目录。相关认证库、邮件工具与依赖已移除，不保留开发免认证入口。

数据库连接与参数留在服务器；浏览器无需账号 Cookie。密钥不进入产物，HTTP 安全头继续保留。APP_URL 为应用地址，不是认证配置；不再使用 BETTER_AUTH_*、SMTP_URL 或 MAIL_FROM。

## 部署、验证与原则

Node standalone + PostgreSQL，Docker 可选。迁移独立执行，备份使用私有 pg_dump，恢复仅限独立空库；源码 `.env` 不复制进运行包。生产要求 HTTPS、最小权限、备份调度、日志与匿名统计保留期。健康检查确认当前公共内容可读，不再依赖四场景账号业务。

测试覆盖知识快照、内容幂等、阅读分组、检索隔离/故障回退、匿名统计和旧接口停用；独立恢复演练确认新库不建账号表，模拟历史表在重复迁移与恢复后完整保留。浏览器检查无会话/计划请求、导航、搜索、阅读与手机布局。

KISS/YAGNI 移除不适合阅读产品的账号链路；DRY 共享内容、依据、输入校验和停用响应；模块按数据、呈现、统计分工。当前保留历史内容结构以避免重写固定版本，不新建内容平台。详见 ADR-005。
