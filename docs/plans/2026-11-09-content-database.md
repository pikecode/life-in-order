# 内容入库实施计划

目标：精选知识条目、行动任务和来源版本入库，页面实际读取数据库，原始快照保留。

1. 增加来源版本、知识条目、内容发布版和任务表，原子导入；重复导入只校验，同版本不同内容拒绝覆盖。
2. 抽取选中正文的标题、正文、成本、收益、证据等级及原始来源，维护任务到知识条目的引用。
3. 迁移时导入 moving-v1 与 moving-v2，再为计划建立内容版本外键；已有计划不重写。
4. 页面和来源页从数据库读取任务；服务端保存检查版本存在。规则继续保持纯函数。
5. 测试提取、幂等、拒绝覆盖、引用、数据库读取；运行测试、类型检查、构建及浏览器检查。

方案比较：只把文件复制入库但继续读文件改动小，不能满足实际内容管理；采用数据库读取，文件仅作为导入输入与原始证据。KISS：单体单库；YAGNI：不建管理后台；DRY：统一导入与内容读取；SOLID：解析、持久化、规则分离。
