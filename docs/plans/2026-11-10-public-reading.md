# 公开阅读：移除账号与计划服务

用户确认产品仅用于浏览阅读，不再需要注册登录。推荐移除认证运行链路，而不是只隐藏入口；同时停用账号依赖的旧计划功能，避免保留失效界面或将历史私人数据暴露给匿名用户。

范围：首页与导航去会话请求和计划入口；旧登录/账号/计划页面转到公开目录，旧认证、计划与账号导出接口返回 410，不再验证、发送邮件、读取或修改历史个人数据。删除认证与旧界面代码、邮件工具及依赖。保留内容快照、公共知识、阅读、检索、匿名统计及备份。

迁移只创建公共内容与统计结构，不再新建用户/会话/计划表，不删除现有表或记录。历史数据仍可通过数据库运维备份保留，不新增匿名导出个人数据的接口。新环境只需 PostgreSQL，应用地址使用 APP_URL，不需 SMTP 或认证密钥。

同步测试、CI、Docker 示例、部署、隐私与当前产品文档。历史内容版本与领域数据不重写。KISS/YAGNI 去掉账号运行负担，DRY 用统一停用响应覆盖旧接口，单一职责保留公共内容与统计边界。

验证：停用接口不论 Cookie 均 410、旧页面重定向、浏览器无认证/计划请求、阅读搜索与统计正常；全新数据库迁移不含账号表、重复迁移保留模拟历史数据、备份恢复、类型检查、测试、构建与生产包。

完成：26 项测试、独立迁移保留/备份恢复、类型检查、构建与生产包浏览器验证通过。详见 verification.md。
