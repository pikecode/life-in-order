# 多场景行动入口与流程计划

目标：提供换工作、租房、失业、出生事务四个完整入口，复用清单与账号能力。

方案：共用场景元数据、规则、保存与跟进组件，优于复制四套页面。KISS/YAGNI 只实现四个有来源流程，不做通用编排后台；DRY 复用任务与引用；SOLID 场景内容、匹配和展示分离。

1. 增加场景配置与租房、失业、出生任务，逐项指向固定版本正文，不新增未经核实的资格结论。
2. 内容发布版增加场景元数据；兼容旧版指纹和计划，导入新版本不覆盖已有任务。
3. 首页为四场景入口与我的计划；独立场景路由共用编辑器，登录组件复用。
4. 校验按场景回答与任务编号；跨场景计划与文件恢复跳转到对应入口，保留草稿与历史。
5. 测试四场景差异、来源、数据隔离及旧版兼容；运行构建与浏览器流程。

出生场景仅组织证件、材料、保险咨询与家庭分工，不输出诊疗或婴儿用药决定。所有地区办理要求仍须向官方渠道确认。
