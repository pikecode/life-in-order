# 首页入口优化

目标：让新用户直接描述问题，也能从具体事件进入行动清单；老用户能快速找到已保存计划。

方案：推荐双入口（自然语言搜索＋场景清单），相比仅美化卡片，可以复用已经完成的语义检索，把当前产品能力呈现在首屏。沿用纸色、深绿及衬线标题，主次由排版与留白区分，不增加装饰性大图或虚构案例。

范围：`home-hub.tsx`、首页专属样式、全站元信息及文档。复用 Next.js Form、知识库 SearchButton、现有主题及场景元数据；搜索跳转知识库，由原检索处理，不自动生成计划。保留账号加载、计划归属和旧版路由逻辑。

步骤：
1. 首屏加入有标签的自由描述搜索、明确的示例问题及知识浏览入口。
2. 用七个现有主题作为浏览捷径，场景清单与知识查找分开说明。
3. 场景入口增加区块标题、原有简介及明确起步链接；我的计划增加导航锚点，不改变获取权限。
4. 调整桌面和手机布局、焦点与等待反馈；减少动态效果，避免版面跳动。
5. 验证首页搜索不重载、查询完整传递、主题及场景链接可用、匿名计划提示、390/320 像素无溢出，执行类型检查与构建。

原则：KISS、YAGNI 不增加聊天代理、推荐算法和装饰依赖；DRY 复用主题、检索及提交状态；首页负责入口，不承担检索和清单规则，保持单一职责。

完成：已实现双入口、示例问题、七主题浏览、场景层级和计划锚点；复用检索与提交组件。桌面/手机截图及搜索导航检查通过，未调整数据与权限逻辑。
