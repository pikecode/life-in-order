# 跨城换工作条件与前置事项计划

目标：按离职、入职和搬迁情况生成清单，解释适用原因和前置准备。

采用显式条件字段与三态匹配，不建设通用工作流引擎。直接改已发布 moving-v2 会影响旧完成记录，因此发布 moving-v3，旧版继续可读写。旧计划另建新版，不自动套用完成状态。

1. 新增就业、入职、搬迁阶段及参保衔接、当地资格、竞业约定问题；未回答保持未知。
2. 任务增加明确适用条件、前置任务及原因说明；保留来源链，不计算法律期限与金额。
3. 页面显示阶段问题、适用理由、前置事项和可以先做的任务；有依赖不强制禁止历史补录完成。
4. 导入新版任务，保留 moving-v1/v2 的内容与数据结构；验证条件变化、未知、依赖、旧数据和新版本隔离。
5. 运行测试、类型检查、构建及浏览器流程。

KISS：有限条件而非规则语言；YAGNI：不做通知和复杂日期计算；DRY：共享问题定义；SOLID：纯规则与展示、数据库分离。
