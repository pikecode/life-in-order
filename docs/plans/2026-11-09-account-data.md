# 账号数据管理计划

目标：导出本人账号及全部计划，经过明确确认与邮箱重新验证注销账号。

采用 Better Auth 内置删除能力及现有外键级联，替代自建注销令牌和队列（KISS/YAGNI）；导出接口服务端校验身份并禁止缓存，不导出会话令牌。认证与业务数据分责（SOLID），复用账号归属和计划结构（DRY）。

1. 增加账号页、账号数据导出接口；对全部计划按稳定结构导出，不把账号备份冒充单计划导入文件。
2. 启用内置删除并要求五分钟内新登录及明确确认标记，页面每次先验证邮箱再确认执行。
3. 删除账户时数据库级联删除会话、登录关联与计划；页面清理匿名草稿并重新加载清除页面数据。
4. 测试未登录、用户隔离、不含令牌、过期登录拒绝、缺少确认拒绝、注销级联及旧会话失效。
5. 本地虚构账号浏览器检查，更新隐私与备份边界。

只删除用户主动确认的账号；本轮测试仅创建并注销专用虚构测试账号。不承诺即时删除备份，也不添加自动邮件或外部消息发送。
