# 首页手册排版

读者视角：首屏重复引导、主题卡片框架偏重、同级箭头太多、随机发现距离入口较远。目标是更容易扫标题，降低浏览目录所需滚动量，保持原有阅读链接与无账号产品边界。

比较：仅修卡片间距成本小但重复层级仍在；推荐使用手册目录行，桌面主题在左、文章标题在右，手机自然堆叠，七主题快速锚点保留但去除胶囊外框。随机区以四条短知识和两篇专题形成不同阅读密度。保留首页精选、固定高度续读、顺序阅读、目录展开和搜索。

范围：HomeHub、RandomDiscovery 文案与首页专属 CSS；复用全部服务端数据、现有六条抽样和链接，不改阅读正文、统计、数据库或接口。清理首页已被覆盖的重复样式，KISS/DRY；不加图片、字体下载、轮播和推荐服务，YAGNI；数据与界面职责保持分离。

验收：320/390/768/1440px 无横向溢出，标题完整，入口至少 44px，主题锚点/章节展开/搜索/随机换组/正文跳转可用，续读载入与清除不推动目录，首页与阅读页往返无样式污染。类型检查和生产构建；限额部署保留旧包。真实读者偏好仍未验证。

实施：主题从三列外框卡片改为桌面目录行、手机自然堆叠；删除重复箭头和开始提示，快捷锚点去胶囊边框，随机四短知识与两专题分层。首页 CSS 合并为一套规则，约 10.7KB，无新增依赖。

验证发现原生首页锚点进入文章后，后退可能只恢复 URL 而保留文章界面；首页两入口、主题跳转及无记录续读统一使用 Next Link，使锚点与现有路由状态同步。浏览器确认两条回归路径：随便翻翻→专题→后退，以及主题锚点→章节→后退，均恢复首页。

类型检查、4 项相关测试和生产构建通过。四断点、目录展开、清除续读无位移、键盘换组保留焦点、排重及搜索提交检查通过。尚未验证真实手机、读屏软件与实际读者偏好。
