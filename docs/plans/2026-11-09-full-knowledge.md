# 全量知识入库计划

目标：固定上游版本的全部 book 正文入库并可检索，行动任务仍人工精选。

1. 获取固定提交的目录树，补齐全部章节快照；核对 Git blob 摘要和本地 SHA-256。
2. 检查章节、条号、字段差异；全量提取知识，缺失字段或重复编号阻止导入，不静默跳过。
3. 保留已存在来源和计划版本，事务补充知识；导入结果明确新增与总数，重复导入无新增。
4. 增加分页知识检索页；来源页仍展示任务直接关联知识，避免一次输出全部正文。
5. 对照仓库目录树、标题与数据库数量，运行测试、类型检查、构建和浏览器检查。

方案：全量知识入库加精选任务优于全部自动任务化，避免把备选与解释变成必须执行项。KISS/YAGNI 不引入搜索服务；DRY 复用知识与来源；SOLID 保持解析、导入、查询与页面分离。
