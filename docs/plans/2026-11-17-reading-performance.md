# 阅读位置保存与统计计时优化

范围：只优化长文位置同步写入和短知识阅读统计计时；不增加缓存服务，不改统计口径、正文、存储格式或数据库。

方案比较：长文按 500ms 节流写入并在离开时补存，推荐；仅防抖会使持续滚动迟迟不落盘。统计使用剩余停留时间的单次定时器，替代每条 250ms 轮询，复用 VisibleDwell，符合 KISS/DRY。集中式统计调度器或通用调度框架按 YAGNI 暂缓。

1. 长文滚动时按帧仅计算位置、暂存内存；500ms 批量写入；visibilitychange 隐藏、blur、pagehide、组件卸载时补存最后前台位置，后台滚动不更新，待确认续读位置不覆盖。
2. VisibleDwell 提供剩余累计时间；ReadingTracker 仅在可见/前台/聚焦/未上报时预约一次计时，离开时暂停，满 10 秒停止；拒绝跟踪时不启动观察器与计时器。
3. 用时钟断言验证暂停、恢复、只上报一次；浏览器拦截统计上报并统计计时器/写入次数，检查离开补存、隐藏不更新、续读和存储失败。
4. 类型检查、针对性测试、构建、服务器限额构建及原子发布，保留旧版。

验证记录：相同 390px 浏览器、同一长文、40 次自动滚动，旧版写入 40 次，新版写入 3 次（单次控制实验，不代表整页性能比例）。新版无 250ms 轮询；浏览器验证可见条目预约计时、模拟后台时取消、返回前台累计满十秒只上报一次、完成后无计时任务。统计请求在浏览器拦截，不污染线上统计。

长文验证：500ms 内 pagehide 补存、实际导航补存、隐藏状态滚动不覆盖、返回续读正常。后台状态通过浏览器属性与事件模拟，尚未覆盖所有真实移动浏览器行为。类型检查、五项针对性测试、本地及服务器限额构建通过。旧格式位置仍可读取，无数据迁移。

完整 41 项测试通过（使用 PostgreSQL 17 客户端）；已发布 `20261117-reading-performance`，保留 `20261117-reader-comfort`。
