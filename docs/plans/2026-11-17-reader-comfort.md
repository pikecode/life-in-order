# 共用阅读设置与长文续读

目标：短知识及完整文档共用本机字号/行距设置；长文按版本与路径保存位置，返回提示，点击恢复。

方案比较：共享组件与 CSS 变量最简单，推荐；全局状态库或数据库配置需额外依赖与身份，按 YAGNI 暂缓。续读采用小节锚点和节内比例，相比绝对像素更能适应字号/宽度变化。KISS/DRY 共用设置；正文与匿名统计不改。

1. `reader-preferences.ts` 校验字号/行距、本机长文位置；非法/损坏记录安全回退。
2. `reader-settings.tsx` 共用入口，三档字号、两档行距、恢复默认、完成/键盘关闭；存储失败仍本页生效。
3. `document-position.tsx` 实际可见且聚焦正文保存节内位置，返回时先询问接着读/从头读，不先覆盖历史；显式锚点链接优先。按来源版本与路径隔离；文章末尾不越界，存储禁用不阻塞。
4. 两种阅读页接入、移动目录/设置布局、隐私及 README 更新。
5. 校验测试、浏览器检查设置共享/刷新/恢复默认、续读提示/点击/从头、不同版本隔离、损坏/禁用存储、移动布局与来源；构建后限额部署保留旧版。

范围外：跨设备同步、账号、数据库迁移和新增阅读工具。

完成验证：类型检查、阅读配置/位置校验及目录/连续阅读共四项测试通过，本地构建通过。浏览器检查字号与行距即时生效、跨阅读页共享、恢复默认、Escape/完成关闭、长文返回提示与点击恢复、从头读、重复恢复位置不偏移、存储禁用时本页设置有效且正文可读、320/390/768/1440px 面板不溢出。浏览器自身刷新/后退可能恢复滚动位置，本站续读组件不主动恢复，保留浏览器原生行为。

实现范围：全文文档均可续读，按版本与路径保存；显式锚点优先，旧位置待用户确认前不覆盖。无数据库迁移、依赖或正文更新。真实移动浏览器及跨设备体验未验证，跨设备同步不支持。

发布：`20261117-reader-comfort`；保留上一版 `20261117-library-polish`，管理服务保持独立运行。
