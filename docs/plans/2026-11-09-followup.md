# 卡点记录与执行跟进计划

目标：每个任务可记录卡点与下一步，保存、刷新、导入导出后恢复；清单集中显示需要跟进事项。

方案比较：在现有计划 JSON 中增加可选字段，改动小且支持计划原子保存；另建跟进日志表适合多人和历史审计，目前暂缓。采用前者（KISS、YAGNI），复用进度校验和保存接口（DRY），规则与界面分离（SOLID）。

1. 进度增加卡点（500 字）和下一步（300 字）可选字段，旧数据仍可解析。
2. 修改状态保留跟进信息；未知任务、过长内容和非法导入继续拒绝。
3. 任务增加输入框，顶部集中展示未完成的等待、待核实、有跟进记录任务；条件失效时仅保留在历史。
4. 测试状态切换、完成退出跟进、条件变化保留、数据库及文件恢复，验证浏览器交互。

不提供通知、自动联系他人或多人协作；记录保存沿用明确的“保存进度”。
