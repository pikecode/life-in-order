# 阅读续接与标题预告实施计划

目标：首页继续上次阅读；每组结尾预告后续三条真实标题。

架构：复用版本化阅读路由及现有数据库查询，用浏览器 localStorage 保存单一阅读位置。正文进入可见区域后更新，不以预载或链接预取保存，不标记已读。不增加账号、依赖、数据库迁移或推荐服务。

技术栈：Next.js、React、TypeScript、Zod、PostgreSQL。

方案比较：本机存储无需账号且不上传位置，推荐；服务器进度可跨设备，但需要身份与额外数据治理，按 YAGNI 暂缓。KISS 保留每组八条；DRY 在原分组查询读取后续标题，不重复请求整组正文。

1. `src/lib/reading-position.ts` 校验来源版本、章节和条号，生成本地阅读链接；测试损坏和非法记录。
2. `src/app/read/reading-position.tsx` 仅保存阅读视口上部对应的可见正文位置，滚动更新，存储不可用时静默降级。
3. `src/app/continue-reading.tsx` 首页展示位置、继续链接及清除按钮；`home-hub.tsx` 接入；不自动跳转。
4. `content-db.ts` 扩充同一查询的标题范围，返回最多三条预告；阅读页展示真实标题及原继续按钮。测试末尾、跨章、不足三条。
5. 更新样式与隐私说明；类型检查、针对性测试、构建和浏览器检查：初访、滚动保存、返首页、恢复位置、清除、存储被禁、隐藏页面、手机布局和标题准确。
6. 服务器限额构建、原子切换，健康检查失败回退，保留上一版。

范围外：收藏、分享、场景入口和算法推荐；不改原文、匿名统计口径及内容发布指针。

已完成：类型检查、本地与服务器限额构建通过；本机记录校验、现有卡片与连续阅读三项针对性测试通过。浏览器检查初访、滚动更新、首页续读、浏览器返回、清除、隐藏状态不更新、存储禁用降级、320px 无溢出及真实三条预告通过。隐藏状态通过浏览器属性模拟验证，尚未覆盖所有真实移动浏览器的后台行为。

发布：`20261117-reading-continuity`，上一版 `20261117-chapter-sheets` 保留。无数据库迁移、依赖及知识内容更新。
