# 章节连页优化

目标：连续阅读按相邻章节分组，一章一张纸页；章名仅在页头出现，条目之间以细线连接；依据用轻量文字入口，保持触摸和键盘可用。

采用章节连页（推荐）而非仅压缩原卡片：前者减少重复章名/外框，更适合连续阅读；后者只适用于浏览列表。复用现有分组八条、来源版本、逐条统计和延伸阅读，不增加数据库结构或依赖，符合 KISS/DRY；暂缓阅读进度持久化，符合 YAGNI。

1. 阅读页按相邻 path 分组，不改变条号和次序，章页头及原文导读按组展示。
2. 条目保留独立锚点和统计观察目标；精简依据入口，来源信息仍完整保存。
3. 增加页纸样式和手机布局，正文保持 16—17px，减少底部留白，入口至少 44px 点击范围。
4. 验证单章/跨章结构、编号、原文、来源版本和依据展开；类型检查及限资源 Linux 构建后发布，保留旧产物。

完成验证：类型检查、本地与服务器构建通过；2 项真实数据库回归测试通过，覆盖同章 8 条和跨章 8 条、来源与原文保留。浏览器验证桌面及 390/320px 无横向溢出、依据触控区域不少于 44px、键盘展开、跨章锚点跳转。已发布 `20261117-chapter-sheets`，保留旧发布目录，无数据库迁移。
