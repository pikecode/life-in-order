# 部署与恢复准备计划

目标：提供可运行交付包、容器配置、健康检查和经过独立数据库演练的备份恢复工具。

采用 Next.js standalone 单体与 PostgreSQL，替代直接复制开发目录；无托管资源创建。KISS 保持单体；YAGNI 不引入集群；DRY 复用迁移与校验；SOLID 运维脚本与业务代码分离。

1. standalone 输出、Docker 多阶段镜像、迁移独立目标与 .dockerignore，构建阶段不携带 .env。
2. readiness 查询数据库及发布内容，失败返回 503 且不暴露内部错误；连接有超时。
3. pg_dump 自定义格式、私有文件、拒绝覆盖；pg_restore 只允许独立空数据库、单事务、无 clean。
4. 自动创建专用源/目标测试库，迁移并写入虚构计划后备份恢复，核对知识与用户进度；演练后仅清理自己创建的临时库。
5. 验证生产运行包与静态资源，记录真实 SMTP、Docker 守护进程及生产部署未验证项。
