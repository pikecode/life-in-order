# 首页服务端拆分与样式清理

目标：首页静态主题/标题留在服务端，只保留搜索及续读交互；清理失效 CSS，按路由加载页面样式。

比较：保守拆分现有组件和样式最小且可验证，推荐；重写设计系统或运行时 CSS 框架增加风险和依赖，按 YAGNI 暂缓。KISS/DRY 公共样式只存一份，按各页布局导入专属 CSS，保留原有相对规则顺序。

1. 将 HomeHub 改为服务端组件；抽出提交搜索统计用的客户端表单，复用 SearchButton 与 ContinueReading，不改变 URL、搜索范围和署名。
2. 用已安装的 CSS 解析器离线整理：删除当前源码确认未引用的历史类规则；复杂伪类保守保留；共享规则合为 globals.css，页面专属规则按首页、知识、资料、连续阅读导入。无需运行时依赖。
3. 在清理前后浏览器对比关键断点和跨页导航，确认样式保留、无闪烁/溢出，搜索、目录、续读及设置可用；检查服务器 HTML 静态主题和表单。
4. 对比同环境构建的 CSS/JS 文件量及浏览器加载量；只报告实测收益，不承诺总提速比例。
5. 类型检查、完整测试和构建后限额部署，保留旧版；不改数据/缓存架构或折叠内容加载方式。

完成：首页 HomeHub 已不在客户端模块清单，搜索表单和续读保留为客户端；移除 233 个未引用选择器，原四份样式合为共享基础及四份路由样式。公共空状态继续共享，移动端、焦点与减少动态规则保留。未新增运行时依赖。

验证：类型检查、完整 41 项测试、本地和服务器限额构建通过。五类页面在 390/768/1440px 对比主要字号/颜色/间距，修复阅读页变量继承顺序；320px 无溢出，跨页搜索/目录/阅读/字号/返回续读、资料空结果样式检查通过。

首屏对比（同一浏览器，排除链接 RSC 预取，压缩体积）：旧版 CSS 18,986 字节，新版 9,363；旧版 JS 174,667，新版 172,563；HTML 15,676 → 15,068。样式解压体积 98,837 → 39,702。常规预取仍可能提前下载目标页资源，不能把上述 CSS 差值当作整次会话全部节省，亦不代表加载时间同比下降。

发布：`20261117-home-bundle`，保留 `20261117-reading-performance`。无数据库迁移或内容修改。尚未做真实弱网手机或压力测试。
