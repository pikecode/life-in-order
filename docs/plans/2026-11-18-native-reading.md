# 原生阅读设置、页面标题与稳定续读区域

目标：修复设置面板焦点离开后 Escape 无法关闭、多个页面标题重复、首页读取本机进度后主题下移。

方案：原生非模态 Popover 与声明式 popovertarget，旧浏览器用现有定位与外部/Escape 降级；不引入 Invoker Commands 或兼容库，避免双重控制。复用当前字号/行距和存储格式，KISS/DRY；不锁焦点，不增加功能工具条，符合 YAGNI。

首页续读区域始终渲染稳定尺寸，无记录时显示可用的阅读提示；有记录后只替换区域内部，不插入新的版块。独立标题采用 Next 元数据，动态内容通过 React cache 与正文共用请求内数据，保持来源公开校验。

1. 共用设置组件改为 button+popover，保留可访问名称、aria-pressed、完成后回焦、窄/矮屏定位和手动降级。
2. 续读区域固定两档响应式高度，较长章节名最多展示两行但保留完整可访问文本，清除后回到阅读提示。
3. 根标题模板、目录/说明静态标题、知识与文章动态标题；404 和未发布版本仍不可见。
4. 单元测试及浏览器原生/降级键盘、跨页设置、延迟脚本下位置稳定、标题与版本边界；类型检查、构建，服务器限额发布并保留旧版。

依据：Modern Web Guidance `html`（非模态 UI 用 Popover）、`declarative-dialog-popover-control`（功能检测及手动回退，内部隐藏后恢复焦点），Next 本机元数据文档。

完成验证：类型检查、43 项测试、本地及服务器限额构建通过。原生浮层在焦点移出后 Escape 仍关闭、完成回焦、外部点击关闭；模拟删除 HTMLElement.prototype.popover 后手动降级正常。320/390/1440px 和 568×320 横屏面板在视口内。动态标题对应真实内容，非法章节及未公开来源仍拒绝访问。

受控对比：同一 390px 浏览器、JS 请求延迟 750ms、预置较长章节名称的本机进度；旧版观察到 home-explore 位移 0.0413，新版未观察到布局位移。清除进度不移动主题区。该结果不代表所有实际用户的 CLS 都为零。

Popover 使用较早可用的 popovertarget，不混用 commandfor；原生支持由 HTMLElement.prototype 的 popover 属性检测。旧浏览器以手动外部/Escape 关闭降级，无新增包。默认不捕获焦点。尚未使用真实旧 Safari/读屏软件测试。

发布 `20261118-native-reading`，保留 `20261117-settings-placement`；数据库与知识正文无变化。
