# 产品需求：探索式生活知识库

更新：2026-11-10。以下定位替代此前以行动清单和问题处理台为主的规划。

## 定位与边界

生活有序帮助用户从感兴趣的主题开始阅读、看懂并追溯生活知识。主体验是兴趣发现与顺序阅读，搜索作为辅助；不承诺完整理解任意描述，不自动给出适用性结论或生成处理流程。

内容固定版本完整收录《高性价比人生指南》34 章 772 条，保留作者、CC BY 4.0、提交及原始章节定位。成本收益与证据来自上游，不能加工成未经验证的可信度分数，不把原条目当成已经重新审核的个体建议。

## 用户与主要路径

有明确问题的人可以用关键词或自然语言检索；尚不确定搜索词的人可以从七个主题与真实标题开始浏览。搜索和阅读无需注册。

首页 → 主题/章节或感兴趣的标题 → 连续阅读页 → 向下读/下一组（含跨章提示）→ 主题末尾换主题。搜索结果也可进入完整阅读。首页不再要求用户选择办事场景、填写个人情况或创建计划。

## 页面与交互

首页：简短引导和同级的七主题展台，提供章节切入点、两条真实标题及总数，尽量从不同章节提供标题以帮助识别兴趣；点击直接进入完整阅读。搜索和示例折叠为辅助。标题链接定位到独立阅读页，不虚构热门、精选或个性化推荐。

知识页：保留主题/章节目录和检索，没有查询时搜索折叠，提供醒目的顺序阅读入口；手机默认折叠目录，常驻一行当前范围，桌面挂载后展开。目录选择或屏幕断点变化会恢复对应默认状态，同一目录内保留主动展开/关闭。左侧目录直接浏览并清除搜索词；结果区的章节线索来自本页真实结果，点击保留查询、清除分页并限定范围。主题和章节筛选可逐层撤销，当前范围清楚显示。线索不代表全部结果分布。

卡片：默认只有标题和正文/摘要，标题直接进入连续阅读。成本收益、章节/条号、证据来源、原始条目和署名统一收入“查看依据与原文”，主动展开后完整展示，不再反复显示标签、编号、匹配方式和多个操作。首页主题卡片的数量与章节统一放入“查看主题目录”。

连续阅读：保留 /read/章节/条目 稳定地址，指定条目作为本组起点，按主题内章节顺序一次显示最多 8 条正文。直接向下阅读，不再每条点一次下一条；组末以“继续读 N 条”显示实际下一组条数，或返回上一组。跨章在正文流标明，主题末尾提供其他主题入口。移除固定底栏及预览弹层，减少操作和信息重复；正文依然使用完整上游“说人话”段落，不以列表摘要代替正文。组内位置范围不代表已读完成率。

桌面与手机均为连续正文流，主题卡片在手机单列展示，使用明确翻组入口，不依赖手势或悬停。原生展开入口可用键盘操作，支持浏览器前后退与减少动画。阅读导航合并主题、位置与章节入口，正文 17px，桌面正文宽约 684px。依据入口 13px、至少 44px 点击高度，标题/正文/来源层级分明。

## 故障与数据

无结果提供扩大范围、清除查询和目录浏览；模型不可用回退关键词检索，不强行降低相关性阈值。加载失败显示错误，不伪造空数据。

使用统计保持最小匿名事件，翻阅按实际打开的知识记录；不采集搜索原文、账号或问题画像。统计不代表理解程度或产品价值，测试流量应清理。

## 无账号与历史功能停用

本站不提供注册、登录、邮箱验证码、个人计划保存或账号管理，所有浏览阅读直接开放。旧账号/计划页面转到知识目录，旧认证、计划与账号导出 API 明确返回 410。历史用户和计划数据继续保留在数据库内，不经公开接口提供，不执行自动删除。新安装不再创建账号表，不需要 SMTP 或认证密钥。

暂缓收藏、已读记录、跨设备续读、个性化推荐、图谱、自动标签和模型拆解。当前位置不是阅读完成率，匿名统计不建立账号画像。

## 方案与验证

推荐探索式知识库，兼顾主动查找与随意浏览；替代方案纯杂志式需要持续专题编辑，本轮仅借鉴其排版。KISS 复用现有应用与数据库，DRY 复用目录与检索，单一职责分离领域、数据与界面，YAGNI 不新增推荐服务。

工程验收：真实标题和数量、筛选保留/清除查询、连续阅读、按需展开、跨分页/跨章及分组顺序、主题末尾、正文完整、来源、焦点、滚动、手机布局、旧入口停用、类型检查、测试和生产构建。产品验收仍需实际观察查找成功率、查询返工、有效阅读及零结果情况；当前不承诺交互改版能提高留存。

## 完整内容阅读（2026-11-10）

短知识用于连续浏览，专题长文用于完整理解，保留全文结构及来源；章节导读连接两种阅读方式。主导航提供专题入口，首页按主题引导、章节首组显示相关专题。资料库默认 9 篇长文，切换可看 34 完整章节、244 历史核实档案和 6 参考文件；档案不作为当前建议混排。辅助搜索覆盖短知识及长文，全部资料可另行检索。卡片只展示标题与短摘要，原始文本及许可等主动展开。
