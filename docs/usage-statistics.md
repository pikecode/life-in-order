# 后台使用统计

统计只保存在现有 PostgreSQL，不在前台显示次数，不接第三方分析平台，不关联邮箱或账号。匿名和登录用户采用同一种短期随机会话标识。

## 查看汇总

```sh
npm run db:migrate
npm run usage:report
# 最近 30 天，参数允许 1–30，默认 7 天
npm run usage:report -- 30
npm run usage:prune
```

报告包括事件数量、短期会话数、搜索方式与范围分布、零结果占比、热门知识及阅读到行动入口的比例。只有数据库权限持有者能执行命令；没有公开统计读取接口或前台数字。

## 记录口径

| 事件 | 触发 | 说明 |
|---|---|---|
| search | 首页或知识库表单提交后返回结果 | 保存模式、范围、结果数和语义服务状态；不保存原始描述及其散列 |
| knowledge_open | 打开知识阅读面板 | 卡片出现在列表里不算阅读 |
| knowledge_engaged | 同次打开累计前台、聚焦 10 秒 | 切后台或失焦暂停，关闭结束；每次打开最多上报一次，不代表读懂 |
| action_click | 点击阅读面板中实际关联行动 | 服务端再次确认知识与场景有关联，不代表完成清单 |

搜索标记只在客户端模块内临时匹配提交与结果，匹配后丢弃；不持久化描述。目录浏览、分页、预取、直接访问或刷新不计搜索。示例链接不属于表单提交，第一版不计入搜索提交统计。失败或中断的搜索结果没有统计，不能把该指标当作全部搜索尝试数。

每个提交有独立 UUID，重复上报同一 UUID 幂等。阅读、有效停留和行动按同一短期会话、知识、事件、场景及固定五分钟时间桶去重；跨桶可再次计数。每会话每小时 600 条软上限，匿名更换标识的伪造流量无法被本方案完全识别，统计不是审计凭证。

零结果占比 = 已返回且计入统计的零结果表单搜索 / 已返回且计入统计的表单搜索。阅读到行动比例按“会话＋知识”配对：报告期内打开过知识，且同一会话随后点击该知识关联行动才计转化，一对只算一次，比例不会因多个场景点击超过 100%。会话数不是人数。

## 数据、边界与隐私

`usage_events` 存事件 UUID、会话 UUID、类型、来源提交/章节/条号、合法场景、搜索模式/范围/结果数量/语义状态，以及服务器时间。没有原始查询、查询散列、邮箱、用户 ID、IP、User-Agent 或完整页面 URL；请求严格白名单，未知字段拒绝。

浏览器 `sessionStorage` 仅存 `lio-usage-session` 的 UUID 和最后事件时间，30 分钟无事件或关闭会话后更换。上报不携带登录 Cookie 或 Referer；DNT/GPC 时不记录。存储不可用、接口失败或数据库不可用均不阻塞正常操作，不弹统计错误。尽力上报不能保证零丢失。

搜索本身仍用 GET 地址，浏览器历史及部署访问日志可能包含描述，和此统计表分开。短期标识不与账号关联，因此不随账号导出、注销定位统计记录；这些事件按统一保留策略清理。

## 保留与部署

事件采用 30 天保留策略。新事件写入和运行汇总时清理到期记录；没有访问或服务停止时不会自动运行清理。生产部署应每天在源码工作目录执行 `npm run usage:prune`，由既有调度系统配置；本轮没有安装系统定时任务。备份副本仍按备份保留规则清理，不因主库删除立即消失。

统计表随基本迁移创建，不要求 pgvector 或模型服务在线。既有备份包含该表及索引，恢复演练已增加非空事件的恢复检查。升级前执行迁移；未迁移时统计会静默失败，使用功能继续可用。

## 验证

自动化检查事件白名单、2KB 请求上限、同源保护、知识引用、场景映射、去重、软限量、保留期、请求失败隔离和前后台累计时钟。浏览器还验证实际事件落库；Playwright 默认会强制前台焦点，本轮使用可见性与焦点事件模拟验证后台暂停，不能把自动化环境的强制焦点当作真实标签状态。

本轮开发与浏览器回归产生的专用会话记录已清理，不作为真实使用量展示或保留。

2026-11-10 定位调整：知识阅读尾部已撤下行动推广，当前主要界面不再触发 action_click；该事件及旧报告保留兼容历史数据，不能用其当前数量评判知识库转化。连续翻阅按实际打开的条目记录 knowledge_open 和独立有效停留。

阅读优先版本：完整阅读页与快速预览复用相同打开/停留逻辑，只有客户端实际挂载打开后才上报，链接预取不算阅读。当前主题位置不代表已读次数，未持久化个人阅读进度。

连续分组版本：观察具体正文块进入视口才记录 knowledge_open；knowledge_engaged 只累计该块可见、页面前台且聚焦的时间。八条预载不会全部计数。列表摘要与依据展开不单独计为完整阅读打开；当前无预览弹层。
